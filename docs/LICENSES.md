# CivicLens AI — Open Source Software Attribution

CivicLens AI is built with open-source technologies. Below is an attribution summary of the core software components, libraries, and frameworks utilized in the application.

## Core Backend Dependencies
- **FastAPI**: Modern, fast web framework for building APIs with Python (MIT License).
- **Starlette**: Lightweight ASGI framework/toolkit (BSD 3-Clause License).
- **Pydantic**: Data validation and settings management using Python type annotations (MIT License).
- **Uvicorn**: Lightning-fast ASGI server implementation (BSD 3-Clause License).
- **PyMuPDF**: Python bindings for the MuPDF library, used for PDF rendering and text extraction (GNU AGPL / Commercial).
- **FAISS (CPU)**: Library for efficient similarity search and clustering of dense vectors (MIT License).
- **Sentence-Transformers / HuggingFace Transformers**: Multilingual text embedding models (Apache License 2.0).
- **Google GenAI SDK**: Official Python client for the Google Gemini API (Apache License 2.0).
- **Playwright for Python**: Reliable end-to-end and browser automation (Apache License 2.0).
- **Pytest & AnyIO**: Automated testing framework and asynchronous I/O utilities (MIT License).

## Core Frontend Dependencies
- **React**: Declarative JavaScript UI library (MIT License).
- **Vite**: Frontend build tooling and development server (MIT License).
- **Tailwind CSS**: Utility-first CSS framework (MIT License).
- **Lucide React**: Clean, lightweight icon suite (ISC License).
